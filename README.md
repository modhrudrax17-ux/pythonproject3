# 🎓 Student Data Organizer (Python)

A simple **Python console-based Student Data Organizer** that helps users manage student records. This project demonstrates the use of **lists, dictionaries, loops, conditional statements, and CRUD (Create, Read, Update, Delete) operations** in Python.

---

## 📌 Features

* ➕ Add new student records
* 📋 Display all student records
* ✏️ Update existing student details
* 🗑️ Delete student records
* 📚 View subjects offered
* 🚪 Exit the application safely

---

## 🛠️ Technologies Used

* Python 3
* Lists
* Dictionaries
* While Loop
* If-Else Statements
* For Loop
* User Input
* Basic CRUD Operations
